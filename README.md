## 🇬🇧 English

An open-source Android WebView wrapper created to play [pokesurvivor.com](https://pokesurvivor.com) on mobile devices, in a convenient and lightweight manner, without high energy consumption

### ✨ Features
* **Full Screen Experience:** Play without address bars or navigation panels.
* **Lightweight & Fast:** Built in native Android Studio using WebView.
* **100% Safe & Transparent:** No added ads, trackers, or modified code.
* **Open Source:** Fully verifiable source code for full community trust.

### 📥 Download
Get the latest `.apk` directly from the **[Releases Section](https://github.com/Jv5915648/PokeSurvivor-Mobile/releases/tag/2.1.1)**.
